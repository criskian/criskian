<details>
<summary><b>How CIO works</b></summary>
<br/>

```mermaid
flowchart LR
    U([WhatsApp user]) --> R{Regex router}
    R -- known intent --> F[Deterministic flows]
    R -- open conversation --> C[Conversation service]
    C --> L[LLM agent<br/>tool-augmented generation]
    F --> J[(Job search and<br/>user profile)]
    L --> J
    J --> U
```

Routing cheap, predictable requests with regular expressions and reserving the LLM for open-ended conversation keeps cost and latency low without losing flexibility.

</details>
